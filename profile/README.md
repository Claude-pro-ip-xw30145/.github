<p>Claude Pro订阅住宅代理IP这个说法里，代理是服务形态，住宅是资源属性。买代理买的是使用权和入口，不是地址本身，分不清这两层，很容易在合同上吃亏。</p>

<p>服务形态决定怎么用。统一入口加认证，配置简单，但所有流量共用一个入口；独立地址分配，来源更干净，管理成本更高。订阅场景多为单人使用，两者都可行。</p>

<p>资源属性决定服务端看到什么。住宅、ISP、机房，差别在注册信息与接入方式，与入口地址无关。入口再干净，资源属性不对，效果也有限。</p>

<p>计价方式跟着形态走。按流量计费的多是统一入口，按地址计费的多是独立分配。订阅用量小，按量计费通常更划算。</p>

<p>举个假设情形：同样标称住宅代理，甲按流量卖、乙按地址卖。每月用量几百次时甲便宜，长期固定使用时乙更可控。</p>

<p>有一个容易忽略的点：日志归属。统一入口模式下平台能看到你访问了哪些目标，独立地址模式下这部分信息更多留在自己手里。对隐私敏感的使用者，这一点值得问清。</p>

<p>稳定性方面，统一入口风险更集中，入口出问题全部受影响；独立地址分散，单点故障影响范围小。</p>

<p>技术上要分清入口与出口。你配置的是入口，服务端看到的是出口，排查问题时先确认出口是谁，别拿入口地址去对。</p>

<p>如果业务需要固定来源，独立地址是更合适的选择。统一入口的出口会变，长期固定用途不适用。</p>

<p>预算有限时，可以主业务用独立地址，其余走统一入口，两套并行，成本可控。</p>

<p>合规提醒：代理只是通道，订阅使用要遵守条款，不得用于共享账号或规避地区限制。</p>

<p>还有一个细节：入口地址与出口地址的对应关系要问清。有些方案一个入口对应多个出口，排查时容易对不上。</p>
